# Ideas

Proposals that have not been decided yet. An idea here is not a plan and authorises no work: what the game does is still governed by [`docs/DECISIONS.md`](../docs/DECISIONS.md) and the other owning documents.

## How it works

- **Folder root:** waiting for a decision.
- **`APPROVED/`:** the owner wants it. Before it is built it still needs a decision record in `docs/DECISIONS.md`, and any conflict noted in the file has to be resolved there.
- **`REJECTED/`:** not doing it. Kept so the same idea isn't pitched again without new evidence.

When an idea moves, add a line under its title with the date and the reason, for example `**Rejected (2026-09-24):** breaks D003's offline freeze.` An idea can be split first if only part of it is wanted.

Each file keeps the pitch as written, then a short **Fit today** section: what already exists, which decisions or rules it touches, and what it would cost. Those notes are evidence for the decision, not a verdict.
