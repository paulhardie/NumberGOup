# Phantom Buffer (Recovery Packages)

*Batch: 2026-09-23 design and mechanics expansion — §4 Retrofitting spatial mechanics (The Tower).*

A Workshop upgrade providing a percentage chance at wave start to generate a temporary, transparent shield over the Number. It absorbs incoming wave hits but cannot be spent on the Rig.

## Fit today

- Crowded space: Armor shrinks hits, Cushion absorbs in tier-scaled hits, Second Wind saves one lethal hit, and the Bulwark Ultimate blocks the next hit completely.
- A second pool next to the Number blurs "health, currency and score are one resource", which is the core of the game.
- A roll per wave needs the saved RNG (D006) and a save field for an active shield.
- Would need to show clearly on the run screen, which D016/D032 keep tight.
