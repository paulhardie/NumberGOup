# Cards

Cards are the 1.1 system (D146). This page owns how they work, which of The Tower's cards are built, how to measure them, and the candidates of our own. Accepted choices are in [DECISIONS.md](DECISIONS.md) (D146). The Tower's numbers are in `data/cards/cards.json`, generated by `tools/import_tower_cards.py` from the community wiki's Cards page; never edit that file by hand.

## How they work

As The Tower has them, from its wiki (read 1 October 2026):

| Rule | The Tower | Ours |
|---|---|---|
| **Opening** | The Cards menu opens at Tier 1 wave 20, whose milestone pays 10 Gems | The same milestone row (D136). Cards appears in the dock at wave 20 |
| **A card** | 20 Gems a draw. The rarity is drawn first (common 80%, rare 17%, epic 3%), then a card of that rarity | The same. Rarities with nothing left to give drop out and the rest keep their proportions, so with no epics built a draw is about 82% common and 18% rare. The screen shows the odds a draw really uses |
| **Levels** | Seven, by copies: the second level at 3 copies, then 8, 16, 28, 48 and 80 (the unlock counts towards the second level). 1,600 Gems to max a card | The same |
| **Maxed cards** | No longer drawn | The same. Once every built card is maxed, the draw says "All found" |
| **Slots** | The first is free; then 50, 100, 200, 300, 400, 500, 600, 750 and 1,000 Gems, up to 10,000 for the 22nd | The same prices, but no more slots than there are built cards to fill them (11 today) |
| **Milestone cards** | Recovery Package Chance (Tier 2 wave 750), Land Mine Stun (Tier 7 wave 250), Nuke, Ultimate Crit and Area of Effect much later | Not built yet, so never drawn |
| **Changing cards in a run** | Allowed, except while a boss or fleet lives; "locked" cards stay all run | **Not yet.** A run takes the cards equipped when it starts, frozen in its starting build, so a resumed run keeps them |
| **Presets** | Saved loadouts | Not built |

**Gems come from:**
- milestones: 10 at wave 20, 15 at 50 and 20 at 90;
- the daily claim: 20 a day;
- Settings → Testing: +◆ 500.

## Built cards

What each does in a run lives in `Cards.EFFECTS` (`src/tower/cards.gd`). Each card's effect goes into the same stat stack as the Workshop and Labs (D119), as an add or a multiplier, or into the run rules.

| Card | Rarity | Lv 1 → Lv 7 | What it does here |
|---|---|---|---|
| Damage | Common | ×1.50 → ×4.00 | Multiplies Damage |
| Attack Speed | Common | ×1.25 → ×2.15 | Multiplies Attack Speed |
| Health | Common | ×1.50 → ×4.00 | Multiplies Health, the Number a run starts with |
| Health Regen | Common | ×1.40 → ×2.60 | Multiplies Regen |
| Range | Common | ×1.15 → ×1.45 | Multiplies Range |
| Cash | Common | ×1.20 → ×2.40 | Multiplies every Cash earned |
| Coins | Common | ×1.15 → ×1.45 | Multiplies every Coin earned |
| Critical Chance | Common | +5% → +11% | Adds to Critical Chance |
| Extra Defense | Common | +5% → +11% | Adds to Defense % (capped at 98%) |
| Fortress | Common | ×1.30 → ×2.20 | Multiplies Defense Absolute |
| Free Upgrades | Rare | +4% → +10% each | Adds to each of the three free upgrade chances |

## Measuring

`tools/sim_runs.gd` plays runs with cards:
- `--cards damage:3,health:1` equips those cards at those levels in every run;
- `--card-sweep LEVEL` plays the seeds with no card, then with each built card alone at that level, and prints the median wave, Cash and Coins of each.

Both combine with `--buy`, `--workshop` and `--workshop-coins`. A build that has just reached wave 20, when Cards open, is about `--workshop-coins 2000 --workshop-plan core --buy core` (median wave 21).

**First sweep** (10 seeds, a wave-21 build bought as core, each card alone; D146):

With no card, the build is a Workshop worth 2,000 Coins: Damage 4, Attack Speed 4, Health 5, Regen 4, Defense Absolute 4. Every seed ends at wave 21, killed by the crowd. The Number peaks at about 180.

**What it says, so far:**
- **The wall at wave 21 is an offence wall.** Only cards that kill faster move it at level 1. Health, Regen and the defence cards don't, even at level 7. The likely reason is that the wave-20 boss soaks the shots while wave 21's crowd arrives. That is inferred, not traced.
- **Damage is the card, as it is in The Tower:** level 1 alone is worth eight waves. Cash at level 7 helps because it buys more Damage in the run.
- **Coins only pays its share.** That makes it the clean income card, as The Tower intends.
- **Ten seeds are a first look, not a verdict.** The test series should repeat this at other builds (a turtle, a later Workshop) and with pairs of cards, since slots make cards a combination question.

## Candidates of our own

These are proposals for the test series, not built. Each is meant to fit the Number's rules (THE_NUMBER.md): one arithmetic idea, nothing that adds percent of max Health, and each opening a strategy rather than only adding stats.

| Candidate | Idea | Strategy it opens |
|---|---|---|
| **Compound** | Clean kills grow the Number by more (D111's kill share ×) | An aggressive build that grows by fighting rather than Regen |
| **Remainder** | A landed ÷ takes less: the divisor is softened | Holding a big Number against Dividers |
| **Unequal** | A Lock in range takes extra damage, or holds for less | Answering the Lock without Knockback |
| **Carry the One** | Each new digit the Number reaches in a run gives a short burst (Regen or Damage) | Pushing the Number up rather than sitting still |
| **Interest** | A higher interest cap | An economy build that banks Cash |
| **Absolute** | The first hit each wave does nothing | Shrugging off chip damage, a light Energy Shield |

The test series should run each one as a `--cards` candidate against The Tower's cards at the same level, then keep the ones that open a build The Tower's cards don't.
